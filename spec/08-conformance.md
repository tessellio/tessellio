# 8. Conformance

The wire format is pinned by two committed files, read by **both** decoders:
the Rust reference implementation and the browser implementation.

## 8.1 The two files

- `vectors.json` — five hand-derived vectors whose payloads are stored
  DEFLATE blocks, so a reviewer can verify every byte without running the
  encoder. The Rust conformance suite reproduces them as byte constants and
  asserts, for each, the field-level decode, the canonical re-encode, the
  decoded cells, and the rejection cases; the browser suite does the same
  through its own parser.
- `corpus.json` — the generated conformance corpus: 72 cases, 47 `roundtrip`
  and 25 `expect-error`, with 55 updates carrying the full expected surface
  as `cells565` hex and 15 large surfaces carrying a byte length and a CRC32
  instead. It is read case by case by both decoders.

There is exactly **one** corpus file. Both consumers resolve to it, so a
consumer pointed at a second copy fails there rather than reading a file
nothing regenerates.

## 8.2 The static checker

`scripts/check-vectors.mjs` checks the corpus's own shape:

- the schema version, and the codec's identity (the name and the wire id);
- the five documented vector ids, exactly;
- every `payload`, `cells565`, part `proto` and `surfaceCrc32` is even-length
  lowercase hex;
- per part: the region's payload lengths sum to the update's `updateBytes`;
- per region: the bounds are inside the update, `1..=262144` payload bytes,
  and, when present, `cells565` is exactly `width * height * 2` bytes of hex;
- the cross-reference that both consumers resolve to the one canonical
  corpus file.

Its own unit suite (`scripts/check-vectors.test.mjs`) exercises every rule
against a mutated copy of the committed files, and requires each mutation to
be rejected.

## 8.3 The generator

The corpus is generated by the reference implementation's generator, and it
is **generated, never written by hand**:

```bash
cd tessellio-core
TESSELLIO_CORPUS_OUT=../tessellio-conformance/corpus.json \
  cargo test --test codec_corpus_gen -- --nocapture
# tessellio-corpus: cases=72 bytes=858978 regions=76
```

## 8.4 The gate

`scripts/conformance-gate.sh` is the whole check, and it runs locally — the
codec has no continuous integration.

```bash
scripts/conformance-gate.sh             # run it
scripts/conformance-gate.sh --update    # regenerate the corpus in place
scripts/conformance-gate.sh --self-test # check the checker
```

The gate:

1. runs the static checker, and folds its verdict into its own;
2. regenerates the corpus into a scratch path and requires it to be
   **byte-identical** to the committed file;
3. counts the generator's "no corpus" marker and requires it to be zero, so
   a deleted or unreadable corpus cannot pass as a green run that compared
   nothing;
4. runs the Rust consumer against the committed file and requires its
   `consumed=ok` marker;
5. runs the browser consumer against the same committed file;
6. with `--self-test`, mutates a copy of the corpus three ways and requires
   each mutation to be noticed.

A gate that cannot fail is not a gate. The self-test is what makes the
gate's own teeth checkable.

## 8.5 Why a mismatch is a failure

A corpus case is not documentation: it is the record of what the codec
produced, byte for byte, under a committed input. A codec change that
alters any byte changes the corpus, and the gate regenerates it and
compares it byte for byte. A difference means the committed corpus no
longer describes what the code does, so either the code change was not
reviewed as a format change, or the corpus was edited by hand. Both are
failures by construction.

When the change is intended, it is committed together with the regenerated
corpus (`scripts/conformance-gate.sh --update`) and the diff is part of the
change's review.

## 8.6 Adding a case

1. Add the case to the generator in
   `tessellio-core/tests/codec_corpus_gen.rs`.
2. Run `scripts/conformance-gate.sh --update` and commit the regenerated
   corpus.
3. Extend the static checker if the case exercises a rule it does not yet
   enforce.

The corpus is generated, never written by hand.
